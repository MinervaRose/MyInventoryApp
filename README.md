## Overview

🏆 Submitted to Udacity in partial fulfilment of the requirements for the **Android Basics Nanodegree by Google** (May 2018).

**Easy Inventory** is a small business inventory management application designed for a bookstore that also sells greeting cards and stationery.

The application allows users to manage products, track stock levels, update inventory, contact suppliers, and maintain product information through a clean and approachable mobile interface.

As the capstone project of the Nanodegree, it brings together many of the core Android development concepts introduced throughout the program.

---

## Project Objective

The goal was to create a complete Android application capable of managing inventory data while providing a polished user experience.

The project combines:

* Database Management
* Data Persistence
* User Interface Design
* CRUD Operations
* Content Providers
* Intents
* Mobile Application Architecture

into a single end-to-end application.

## Application Features

📚🎀🏪

The application allows users to:

* View inventory items
* Add new products
* Edit existing products
* Delete products
* Track inventory quantities
* Increase and decrease stock levels
* Contact suppliers directly
* Insert sample data
* Manage product details

Each product includes:

* Product Name
* Category
* Price
* Quantity
* Supplier Name
* Supplier Phone Number

## Design Philosophy

One aspect of this project I particularly enjoyed was designing a friendly and approachable inventory system.

Inventory software often feels overly technical.

The goal here was to create something that felt welcoming and easy to use, especially for small independent businesses.

The bookstore theme, custom illustrations, and soft colour palette were all chosen to make inventory management feel less intimidating.
